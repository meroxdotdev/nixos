# nixos

Personal NixOS configuration — daily driver + homelab management workstation.

## Structure

```
nixos/
├── flake.nix              # entry point — declares inputs and outputs
├── flake.lock             # locked input versions (auto-generated, commit this)
├── hosts/
│   └── <hostname>/
│       ├── configuration.nix          # system-level config (hardware, services, users)
│       └── hardware-configuration.nix # auto-generated by nixos-generate-config
├── home/
│   └── merox/             # Home Manager — user packages, dotfiles, shell, editor
├── modules/               # reusable NixOS/HM modules shared across hosts
└── secrets/               # sops-nix encrypted secrets (.sops.yaml + *.yaml)
```

## Prerequisites

- [Nix](https://nixos.org) with flakes enabled
- [sops-nix](https://github.com/Mic92/sops-nix) for secrets (reuses AGE key from infrastructure repo)

## Apply

```bash
sudo nixos-rebuild switch --flake .#<hostname>
```
